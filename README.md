# Autonomous Testing Engineer

World-Class Autonomous AI Software Testing & Production-Readiness Platform.

## Repository Structure

- `backend/`: FastAPI Control Plane, Universal System Model, Intelligence Engines, Workers, Evidence, RCA, Readiness Engine.
- `frontend/`: Next.js Command Center UI (Dashboard, Live Stream, System Map, Findings, Reports, Benchmarks).
- `workers/`: Execution workers (API, Browser, Performance, Security, Database, AI/LLM, ML, Sandbox).
- `benchmark/`: Ground-truth benchmark applications, defect catalog, and automated evaluator.
- `infrastructure/`: Docker & Deployment configurations.
- `docs/`: Architecture & PRD documentation.
